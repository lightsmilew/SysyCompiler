# 设计文档

## 前言

本文档为 2025 年毕昇杯编译大赛参赛队伍 移进规约都队 的编译器设计文档。本编译器面向官方提供的 sysy 语言，以 llvm 为 ir，以 riscv 为最终目标代码的体系结构。

## 前端部分

前端使用 antlr4 进行词法分析和语法分析生成解析树(parse tree)，然后使用 visitor 模式遍历解析树，生成抽象语法树（AST）。除此之外还进行了必要的语义分析，包括类型检查、符号表管理等。

## 后端部分

后端负责将中间代码转换为目标机器代码（RISC-V 汇编），是编译器的最后阶段。本编译器后端采用经典的三阶段设计：指令选择 → 寄存器分配 → 代码生成。

### 后端整体架构

```
IR代码 → 指令选择 → 寄存器分配 → 汇编生成 → RISC-V汇编
```

### RISC-V 数据结构

后端使用一套完整的 RISC-V 数据结构来表示目标代码：

- **`RISCVModule`**: 顶层模块，包含所有函数和全局变量
- **`RISCVFunction`**: 函数单元，包含基本块序列、栈帧信息和活跃性分析结果
- **`RISCVBasicBlock`**: 基本块，包含指令序列和控制流信息
- **`RISCVInstruction`**: 指令表示，支持 R/I/S/B/U/J 型指令和伪指令
- **`RISCVRegister`**: 寄存器抽象，支持虚拟寄存器和物理寄存器
- **`RISCVOperand`**: 操作数，支持寄存器、立即数、内存地址和标签
- **`RISCVGlobalBlock`**: 全局数据块，处理全局变量和常量池

#### 栈帧设计

栈帧采用标准的 RISC-V ABI 布局：

```
高地址 (函数入口时的 sp)
+------------------+ <- sp (函数入口)
| raStackSize      | ← 保存返回地址 ra 寄存器
+------------------+
| valueStackSize   | ← 局部变量、临时值、alloca等
+------------------+
| argStackSize     | ← 为调用其他函数预留的参数空间
+------------------+ <- sp (函数执行中)
低地址
```

### 指令选择

指令选择器（`InstructionSelector`）将 IR 指令转换为 RISC-V 指令序列：

1. **模式匹配**: 根据 IR 指令类型选择对应的 RISC-V 指令模板
2. **操作数转换**: 将 IR 操作数转换为 RISC-V 操作数（寄存器/立即数/内存）
3. **复杂指令分解**: 将复杂操作分解为多条基本指令
4. **ABI 遵循**: 确保函数调用、参数传递符合 RISC-V ABI 规范

主要处理的指令类型：

- 算术运算（add, sub, mul, div 等）
- 逻辑运算（and, or, xor, shift 等）
- 内存访问（load, store）
- 控制流（branch, jump, call, ret）
- 浮点运算（fadd, fsub, fmul, fdiv 等）
- 类型转换（int↔float）

### 活跃性分析

`LivenessInfo`类提供精确的活跃性信息：

- **活跃区间**: 每个寄存器的多段活跃范围
- **使用点/定义点**: 精确的 def-use 链信息
- **冲突检测**: 判断寄存器间是否存在生命周期重叠
- **溢出决策**: 为寄存器分配提供溢出代价信息

采用图着色算法进行寄存器分配，实现了两种分配器：

#### 图着色寄存器分配器（GraphRegisterAllocator）

基于《虎书》的经典算法，包含以下阶段：

1. **BUILD**: 构建冲突图和移动指令图

   - 活跃性分析计算寄存器生命周期
   - 构建寄存器冲突关系
   - 识别可合并的移动指令

2. **SIMPLIFY**: 简化低度数节点

   - 移除度数小于 K 的节点（K 为可用寄存器数）
   - 将节点压入栈中

3. **COALESCE**: 合并移动相关的寄存器

   - Briggs 保守合并策略避免增加着色复杂度
   - 减少不必要的移动指令

4. **FREEZE**: 冻结移动指令

   - 当无法继续合并时，放弃部分移动指令的合并

5. **SPILL**: 处理溢出

   - 选择溢出代价最小的寄存器
   - 生成 load/store 指令访问内存

6. **SELECT**: 实际着色
   - 从栈中弹出节点并分配颜色
   - 处理溢出寄存器的重写

### 代码生成

`AssemblyEmitter`负责最终的汇编代码生成：

1. **全局数据段**: 生成.data 段的全局变量和常量
2. **函数序言**: 生成栈帧建立代码
3. **指令序列**: 将 RISC-V 指令转换为汇编文本
4. **函数尾声**: 生成栈帧恢复和返回代码
5. **符号解析**: 处理标签和跳转目标
